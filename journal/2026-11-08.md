## Ce que j'ai compris
- Git ≠ GitHub : l'outil d'historique d'un côté, le site qui l'héberge de l'autre.
- Un dépôt = un projet : le code du budget (privé) est séparé de mes notes (public, portfolio).
- Un dépôt doit être créé vide sur GitHub si on a déjà un historique local, sinon les deux historiques entrent en conflit.
- Une GitHub App reçoit des droits précis sur des dépôts choisis : c'est le principe du moindre privilège.
